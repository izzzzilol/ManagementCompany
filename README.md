## 📌 О проекте

Курсовой проект — компактная система учёта для управляющей компании. Приложение полностью
работает офлайн: данные хранятся в локальной базе `uk.sqlite`, сервер не нужен.

Главный экран — **рабочий стол** со сводкой, финансами, последними заявками и быстрыми
действиями. Из него открываются семь реестров с полным CRUD, поиском, карточками записей
и переходами между связанными объектами.

> **Коротко:** 7 таблиц, Room, современный интерфейс на системных виджетах, ноль сторонних UI-библиотек.

## ✨ Возможности

- 🏠 **7 реестров** — дома, квартиры, собственники, услуги, начисления, заявки, расходы.
- ✏️ **Полный CRUD** — добавление, просмотр, изменение и удаление записей.
- 🧭 **Панель команд** — навигация по записям, поиск по `Id`, открытие, редактирование, удаление.
- 📊 **Рабочий стол** — статистика, индикатор оплаты, последние заявки, быстрые действия и реестры.
- 🔗 **Связи между данными** — внешние ключи расшифрованы, связанные записи открываются в один клик.
- 👤 **Карточка собственника** — вкладки «Собственник» и «Записи» с его квартирами, заявками и начислениями.
- 🎨 **Современный интерфейс** — структурированные карточки, однотонные кнопки и иконки, `ActionBar` отключён.

## 🛠 Стек разработки

| Слой | Технология |
| --- | --- |
| Язык | **Java 17** |
| Платформа | **Android**, minSdk 24 / targetSdk 37 |
| База данных | **Android Room 2.8.5** (`@Entity`, `@Dao`, `@Database`) |
| Сборка | **Gradle 9.6.0** + **Android Gradle Plugin 9.4.0** |
| UI | Framework-виджеты, XML-лэйауты, кастомные `@drawable` и `@style` |
| Архитектура | `Activity` → `AppRepository` → `AppDao` → `AppDatabase` |

Без Kotlin, без Compose, без сторонних библиотек — только платформенные API и Room.

## 🗂 Структура данных

| Таблица | Назначение |
| --- | --- |
| `Houses` | Дома |
| `Kvartira` | Квартиры (дом, собственник) |
| `Cobstveniki` | Собственники |
| `Yslygi` | Услуги и тарифы |
| `Nachislenie` | Начисления по квартирам |
| `Zaivki` | Заявки собственников |
| `Rashod` | Расходы по домам |

Внешние ключи описаны аннотациями `@ForeignKey`, поля-ссылки проиндексированы через `@Index`.
При первом запуске база создаётся и заполняется демонстрационными данными в `RoomDatabase.Callback`.

## 📁 Ключевые файлы

```text
app/src/main/
├── java/com/example/managementcompany/
│   ├── MainActivity.java        # рабочий стол
│   ├── TableActivity.java       # реестр таблицы + панель команд
│   ├── RecordActivity.java      # добавление / изменение
│   ├── DetailActivity.java      # просмотр записи и статусы
│   ├── OwnerCardActivity.java   # карточка собственника
│   ├── AppRepository.java       # API для экранов
│   ├── AppDatabase.java         # синглтон Room + сиды
│   ├── AppDao.java              # запросы
│   ├── *Entity.java             # 7 сущностей
│   ├── Ui.java / FormFields.java / TableDefinition.java
├── res/layout/                  # экраны и шапка
└── res/drawable/                # однотонные кнопки и карточки
```

## 🚀 Сборка

Откройте папку `ManagementCompany` в Android Studio и нажмите **Run**, либо из терминала:

```bat
gradlew.bat assembleDebug
```

Готовый APK: `app\build\outputs\apk\debug\app-debug.apk`.
